The Family Recipe App

Dozens of family recipes became a private, live, multi-user web app my family, mostly used mobilly, running entirely on free-tier infrastructure, with AI turning a photo of a handwritten card into a structured, editable recipe in seconds.

Cloudflare PagesCloudflare Access Pages FunctionsD1 (SQLite) R2 object storageClaude API (vision) Vanilla JS PWA$0/mo infra

Screenshots use mock data, the real app is private to my family, which is the point. The live app sits behind Cloudflare Access: family members sign in with one tap via Google against an explicit email allow-list.

Architecture

family phones ──▶ recipes.<family-domain>.com   (Cloudflare DNS, proxied)
                    │  Cloudflare Access via Google SSO, email allow-list, JWT per request
                    ├─ static PWA shell        ← Cloudflare Pages (vanilla JS, no framework)
                    └─ /api/*                  ← Pages Function (one file)
                          ├─ recipes CRUD       → D1  · versioned edits · soft delete
                          ├─ likes              → D1  · per-user, drives "liked-by" filters
                          ├─ photo store/serve  → R2  · gated, private
                          └─ /api/transcribe    → Claude Haiku vision · photo → structured draft
Auth
Cloudflare Access in front of everything; the API validates the Access JWT signature against team public keys on every request, identity is cryptographic, never a trusted header.
Data
Recipes live in D1 (SQLite at the edge). Every edit snapshots the prior version which makes deletes soft with an "undo last edit" button.
AI ingestion
1–2 photos of a card (single or double-sided) go to Claude Haiku vision with a strict transcription prompt: never invent unreadable text, mark estimated times, infer cuisine/effort. The draft opens in the same editor for human review before anything saves.
Cost engineering
Everything rides free tiers (Pages, Access ≤50 users, D1, R2). The only metered call is transcription: ~1¢ per recipe, with a family-wide daily cap enforced in D1 so a bug can never run up a bill.
Attribution
Every recipe permanently shows who added it; "edited by" appears only after someone changes it. Filters: ingredient search, total-time slider, cuisine, liked-by, and added-by.
